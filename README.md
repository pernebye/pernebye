# Bekarys Pernebayev

Founder / CTO at [Ozimiz](https://ozimiz-it.com) — we build ERP and process automation
for companies in Kazakhstan.

Most of my work lives in private repos; pieces that turn out generic enough get
extracted here:

- [llm-scheduler](https://github.com/pernebye/llm-scheduler) — Postgres job queue for LLM agents: prepare ahead of time, deliver on time
- [pg-hybrid-search](https://github.com/pernebye/pg-hybrid-search) — hybrid RAG retrieval on plain Postgres: tsvector + pgvector + RRF, no extra infrastructure
- [hash-chain-ledger](https://github.com/pernebye/hash-chain-ledger) — tamper-evident append-only log, sha256 chain over canonical JSON
- [kz-ofd-receipts](https://github.com/pernebye/kz-ofd-receipts) — parse Kazakhstan fiscal receipts from their QR links
- [llm-pii-anonymizer](https://github.com/pernebye/llm-pii-anonymizer) — strip PII from free-form text with Claude, regex fallback when offline
- [claude-file-toolkit](https://github.com/pernebye/claude-file-toolkit) — let a Claude agent hand you a real PDF, DOCX or XLSX instead of a wall of markdown
- [llm-latex-repair](https://github.com/pernebye/llm-latex-repair) — fix LaTeX that JSON.parse mangles in LLM output
- [starfield-canvas](https://github.com/pernebye/starfield-canvas) — tiny canvas starfield for hero sections
- [code-rain-canvas](https://github.com/pernebye/code-rain-canvas) — falling syntax-highlighted code, same idea in a different weather

TypeScript / Node / Postgres, some Python. Almaty.
